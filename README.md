API-REST

Projeto de estudo focado na prática de conceitos de APIs REST — construção de endpoints, verbos HTTP (GET, POST, PUT, DELETE) e estrutura básica de uma aplicação Java seguindo o padrão REST.

Objetivo

Exercitar na prática o funcionamento de uma API REST: como os endpoints são definidos, como as requisições e respostas são tratadas, e como organizar um projeto Java para esse fim.

Tecnologias
Java
REST APIs

Contexto:
Projeto acadêmico/exercício, desenvolvido para consolidar o entendimento de arquitetura REST antes de aplicá-la em projetos maiores.
